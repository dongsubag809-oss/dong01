긴급 안내

시간 예약은 자동제어 메뉴에서 동·장비별로 설정할 수 있습니다. 실제 결선과 고정 DO 주소를 확인하세요. 온습도 센서 미수신과 창문 DI 리미트 미확인 장비의 자동 출력은 차단됩니다.

환경설정 · 사용자 이름 변경

하우스 5개 이름과 각 하우스의 제어 접점 표시 이름을 자유롭게 변경합니다. 이름만 변경하며 PLC 주소와 출력 동작은 변경되지 않습니다. PLC ID 1과 ID 2의 DO01~DO64 총 128점은 고정 주소이며, 사용자 지정 이름만 변경됩니다. 장비별 실제 결선은 배선표 확인 전까지 임의 배정하지 않습니다.

Wi-Fi 프로그램 업데이트

GitHub 정식 APK를 Wi-Fi로 내려받아 SHA-256을 검증합니다. Android 7.1 HMI에서는 설치 승인 화면을 열고, Android 8 이상에서는 파일 저장 후 설치합니다. 사용자 승인 없이 설치하지 않습니다.

새 버전을 검색하려면 업데이트 검색을 누르세요.

PLC 운전 중에는 APK 설치를 수행하지 마세요. Play Protect 차단 경고가 나타나면 설치를 취소하고 관리자에게 확인하세요.

HMI LAN 자동검색 UDP 포트: 38541

진행 순서: 업데이트 검색 → APK 다운로드 및 SHA-256 확인 → 설치 승인. Android 설치 권한 승인 요청이 나타나면 해당 권한을 확인한 뒤 설치 승인을 다시 누르세요. Play Protect 경고를 우회하지 않습니다.
