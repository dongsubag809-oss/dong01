환경설정 · 사용자 이름 변경

하우스 5개 이름과 각 하우스의 제어 접점 표시 이름을 자유롭게 변경합니다. 이름만 변경하며 PLC 주소와 출력 동작은 변경되지 않습니다. PLC ID 1과 ID 2의 DO01~DO64 총 128점은 고정 주소이며, 사용자 지정 이름만 변경됩니다. 장비별 실제 결선은 배선표 확인 전까지 임의 배정하지 않습니다.
