# ENERGYBLUE 온습도 센서 통신 기준 및 검토 이력

갱신: 2026-11-06 / 프로그램 V5.09

## 설치 및 현장 확인 상태

- 사용자: HMI IXP101H1 COM6에 RS485 온습도계를 연결. 1번동 내부 온습도용.
- 상품 사진: 회색 벽부형 왕자형 외함, 파란 라벨, 작은 OLED Tem/Hum 2행, PVC 프로브, 115×85mm. 상품 모델 표기는 RS485뿐이다.
- 정확한 제조사, 펌웨어, 현재 ID 및 HMI COM6의 Linux 경로는 미확정.
- V5.09 기본 /dev/ttyS6는 현장 시험용 후보이다. 실제 경로로 확정하지 않는다. COM5 설정 경로 및 별칭과 중복되면 차단한다.
- 실제 HMI/COM6/센서와 직접 접속할 수 없는 개발 환경이므로 현물 수신, 배선, 권한, OLED 대조는 미검증.

제품/다운로드 원문:

해당 페이지의 OLED 매뉴얼 링크(12쪽 4.3~4.4):

| 항목 | 이 제조사 모델의 문서상 사양 |
|---|---|
| 기본 통신 | 4800bps, 8N1, ID1 |
| 습도 | 0x0000, unsigned 16비트, ÷10 %RH |
| 온도 | 0x0001, signed 16비트 2의 보수, ÷10 °C |
| 데이터 바이트 | 상위 바이트 먼저; CRC 하위 바이트 먼저 |
| 읽기 | FC03, 시작0, 2레지스터 |
| ID 설정 | FC06, 0x07D0, 1~254; 설정 후 센서 전원 재인가 |
| 속도 설정 | 0x07D1; 0=2400, 1=4800, 2=9600 |
| 읽기 예 | 01 03 00 00 00 02 C4 0B |

이 모델은 117×87×43mm, 기본4800, 표시 형식/프로브 선택 등에서 판매 사진과 차이가 있다. 이 문서의 ID 쓰기를 구매품에 자동 적용하지 않는다.

### 다른 문서와의 차이

- 上海岐洛 공식 제품 페이지: 온도0x0001, 습도0x0002를 명시.
  https://www.shanghaiqiluo.com/product/wenshidu/
  이 페이지에서 배율은 확인되지 않아 해당 맵은 프로그램에 적용하지 않았다.
- ATO 공식 통신 문서도 습도0, 온도1, ID0x07D0를 사용하지만 동일 구매품이라는 근거는 없다.
  https://www.ato.com/Content/doc/accurate-temperature-humidity-sensor-communications-protocol.pdf
- 서로 다른 중국 제품의 ID 쓰기 주소는 다르다. 0x0002/0x0100/0x07D0 중 외형만 보고 선택하지 않는다.

## V5.09 구현 범위

- 독립 SensorSerial / sensor_serial.c: 별도 네이티브 라이브러리와 fd. COM5 소스/PLC 명령맵 그대로 유지.
- 네이티브 전송은 FC03/04, ID1~247, 시작0, 길이2만 허용. FC05/06/16 등 쓰기는 이중 차단.
- 기본 h0t1 ÷10은 위 제조사 원문으로 근거가 있는 시험 후보이며 구매품 확정 맵이 아니다.
- 대안 t0h1 ÷10은 昆仑 IS1900 원문 5~6쪽의 온도0/습도1, signed16, ÷10 정의를 근거로 한 타제품 시험 후보이다. 구매품 일치는 미확정.
  https://mkp-res.hc-cdn.com/marketplace/public/app/attachment/20211217/d67a8d00-51e8-4cb9-8c68-09bd47cf1ed1/2112171014058811.pdf
- 모든 맵은 OLED 대조 전 시험 수신으로 표시하며 이력·자동제어 측정값에 주입하지 않는다.
- 사용자가 현재 수신값과 실제 OLED의 온도·습도 일치를 확인해야 1동 현재값·이력에 연결된다. 현장 확인은 정확한 제조사 맵 확보를 대신하는 제조사 인증이 아니다.
- 경로/ID/속도/맵 변경, 검색은 일치 확인을 초기화. 통신 끊김/CRC/범위 오류는 현재값을 비운다.
- 원문 TX/RX, 오류/Modbus 예외 표시, 타임아웃, 재접속, 비동기 ID·속도 검색과 취소.
- 온습도 조건의 물리적 자동 출력은 이번 통신 확인 버전에서 계속 잠금. 기존 시간 예약/수동/휴대폰/정역 인터록 유지.
- 센서 ID 변경 기능은 정확한 모델의 설정 맵이 확인된 다음 버전에 추가한다. 이번 버전은 현재 ID 검색/읽기만 한다.
